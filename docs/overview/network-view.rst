################################
ATS Software Communication View
################################

This draft focuses on logical software communication paths that may be useful when debugging network connectivity.
It complements the :doc:`deployment-diagram`, which shows physical host and rack connections.
The dashed links below are logical relationships and do not imply direct wiring or a specific network route.
Physical cables are shown in the deployment diagram.
