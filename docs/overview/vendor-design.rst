#####################
Vendor Design Context
#####################

Tekniker designed and documented the original ATS hardware, deployment approach, simulation architecture, and pre-shipment test plan.
That material provides historical context for the system's controller boundaries, simulator roles, networking, and safety interfaces.

This site summarizes that context in original documentation for the Rubin-operated ATS.
It does not reproduce the vendor manuals, diagrams, screenshots, electrical schematics, or other vendor assets.
Current Rubin procedures, approved configuration records, and safety documentation take precedence over the historical design material.
