########################
ATS Deployment Diagram
########################

This draft physical view summarizes the ATS hosts and hardware described in :doc:`hardware` and :doc:`virtual-machines`.
It is intended to show where the components are deployed and which devices connect to the rack switch.

It is a logical overview, not an approved network or safety drawing.
Several service placements and network details are not specified in this repository.
Use approved ATS configuration records for deployment decisions.
