##################
Bosch Power Supply
##################

Status
######

Active.

Purpose
#######

The Bosch power supply simulator supplies the power-status inputs required by the TMA controller.

Interfaces and dependencies
###########################

It consumes simulated controller variables through :doc:`read-variables` and is deployed on the supporting Windows host.

Repository
##########
