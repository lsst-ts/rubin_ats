###############
Automated Tests
###############

Status
######

Active.

Purpose
#######

The automated-test component contains the Robot Framework suite used to validate ATS behavior before broader functional testing.

Interfaces and dependencies
###########################

It runs from the supporting Linux environment and targets the ATS controllers, database, and simulator endpoints.
It uses :doc:`speedgoat-manager` when exercising main-axis simulation.
