Limits
######

Status
######

Active.

Purpose
#######

The limits simulator derives simulated limit-switch behavior from subsystem position and controller variables.

Interfaces and dependencies
###########################

It uses :doc:`read-variables` and TekNSV values, and is normally combined with the affected subsystem simulator rather than tested in isolation.
