####################
WriteTekNSVVariables
####################

Status
######

Active.

Purpose
#######

WriteTekNSVVariables sets simulation-facing TekNSV values, including deployable-extension state and brake-pressure values.

Interfaces and dependencies
###########################

It writes to the TMA PXI and supplies safety-related inputs to simulators such as deployable extensions and the Oil Supply System.

Repository
##########

``ts_tma_hil_write-TekNSV-variables``
