###################
Motor Thermal Model
###################

Status
######

Active.

Purpose
#######

The motor thermal model simulates phase-drive and cabinet thermal behavior.

Interfaces and dependencies
###########################

It uses ReadVariables instances for TMA PXI and AXES PXI data and TekNSV values for ambient-temperature inputs.

Repository
##########
