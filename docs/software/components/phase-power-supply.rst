##################
Phase Power Supply
##################

Status
######

Active.

Purpose
#######

The phase power supply simulator provides the power-supply states and faults used by the TMA controller.

Interfaces and dependencies
###########################

It consumes TMA PXI variable data through :doc:`read-variables` and safety-related values through TekNSV.

##########
