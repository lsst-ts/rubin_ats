#################
Speedgoat Manager
#################

Status
######

Active.

Purpose
#######

Speedgoat Manager controls the model running on the Speedgoat, including model lifecycle and injected drive or encoder faults.

Interfaces and dependencies
###########################

It manages the :doc:`main-axes` model and is used by automated tests through its Python interface.
The released manager binaries must be deployed as a compatible pair with the approved main-axis model binaries.
