###############################
Cabinet Temperature Controllers
###############################

Status
######

Active.

Purpose
#######

This component simulates the standalone temperature controllers used by the TMA cabinets.

Interfaces and dependencies
###########################

It provides Modbus services to the AUX PXI and uses TMA PXI variable data where required.
Its addresses and ports must match the approved AUX PXI mappings.

Repository
##########

``ts_tma_hil_cabinet-temperature-controller_cabinets``
