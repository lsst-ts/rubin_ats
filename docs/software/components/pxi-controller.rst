##############
PXI Controller
##############

Status
######

Active.

Purpose
#######

The PXI controller software builds and operates the TMA, AXES, and AUX real-time applications.

Interfaces and dependencies
###########################

It connects the ATS controller applications to EtherCAT, network shared variables, safety mappings, encoder configuration, and simulator endpoints.
See :doc:`../../deployment/index` for the controller-specific deployment runbooks.

##########
