##############
Secondary Axes
##############

Status
######

Active.

Purpose
#######

The secondary-axis SIL simulates Bosch auxiliary axes with a configured instance for each axis.

Interfaces and dependencies
###########################

It runs on the supporting Linux environment and provides Modbus behavior to the TMA PXI.
The TMA PXI Bosch SIL configuration identifies its approved endpoint.

Repository
##########

``ts_tma_hil_secondary-axis_secondaryaxissil``
