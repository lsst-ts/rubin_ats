#########
Main Axes
#########

Status
######

Active.

Purpose
#######

The main-axes model simulates azimuth and elevation mechanics, phase drives, and encoder behavior on the Speedgoat target.

Interfaces and dependencies
###########################

The AXES PXI exchanges real-time EtherCAT data with the Speedgoat.
The model is managed by :doc:`speedgoat-manager` and must be available before AXES PXI EtherCAT validation.

Repository
##########

``ts_tma_hil_main-axes_lsst-hil``
