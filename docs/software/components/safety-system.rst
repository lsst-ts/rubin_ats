#############
Safety System
#############

Status
######

Active.

Purpose
#######

The safety-system component simulates the TMA interlock system on the Pilz controller.

Interfaces and dependencies
###########################

It receives simulated inputs through Modbus from the TMA PXI and drives the Speedgoat safety-related signals.
TekNSV values support simulated limits and emergency-stop inputs.

Repository
##########

``ts_tma_hil_test-dual-modbus``
