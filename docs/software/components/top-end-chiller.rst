################
Top End Chiller
################

Status
######

Active.

Purpose
#######

The Top End Chiller simulator provides the chiller service used by the ATS.

Interfaces and dependencies
###########################

It exposes a Modbus endpoint to the AUX PXI.
The deployed server address and port must match the approved AUX PXI configuration.

Repository
##########
